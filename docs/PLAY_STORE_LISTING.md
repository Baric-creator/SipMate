# SipMate — Google Play Store listing draft

## App name
SipMate

## Short description
Find people nearby who are ready for a drink, coffee or casual hangout.

## Full description
SipMate helps you discover people nearby who are up for a drink, coffee or casual meetup right now.

Open the app, see who is nearby, check what they are currently up for and send a Cheers 🍻. When both people send Cheers, you are connected and can start chatting.

SipMate is built around real-time social discovery rather than endless swiping.

Key features:
- Discover nearby people
- ACTIVE / INACTIVE availability
- See what someone is currently up for
- Send Cheers 🍻
- Mutual Cheers unlocks chat
- Realtime messaging and read status
- Block and report tools
- Premium discovery and messaging features
- English, German and Croatian interface

SipMate is intended for adults. Always meet responsibly, use public places for first meetings and never drink and drive.
